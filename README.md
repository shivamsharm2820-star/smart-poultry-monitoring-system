# smart-poultry-monitoring-system
  A smart poultry monitoring system using Arduino Uno,DHT22 Sensor,Relay module,LED

  

Applications

 •	Poultry farms
 •	Chicken hatcheries
 •	Broiler farming
 •	Layer farms
 •	Livestock monitoring systems 

Components
 1.	Arduino Uno
 2.	DHT22 Sensor 
 3.	Relay Module (5V) 
 4.	BuzzerApplications
 5.	LED

Temperature and humidity readings
| Temperature (°C) | Humidity (%) | Status                     |
| ---------------- | ------------ | -------------------------- |
| 25°C             | 50%          | Normal                     |
| 28°C             | 60%          | Good                       |
| 30°C             | 65%          | Ideal for young chicks     |
